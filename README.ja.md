# Composa

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

Composa は、レイヤーを使った画像合成とレタッチのための画像エディターです。Photoshop に似たツールとショートカットを備えています。Robbie Tilton によるオープンソースの macOS アプリ [Compositor](https://github.com/robbietilton/Compositor) の機能を、C#、.NET 10、[Avalonia](https://avaloniaui.net/)、[SkiaSharp](https://github.com/mono/SkiaSharp) で一から実装しています。

主に Linux の X11 と Wayland（XWayland 経由）で開発されています。Windows 版も公開され、変更ごとに Windows でテストが実行されますが、実際の利用による検証は Linux 版のほうが進んでいます。macOS 版は計画中です。

デモ動画は [英語版 README](README.md) をご覧ください。詳細な[ユーザーガイド](docs/README.md)は現在英語です。

## 表示言語

**ヘルプ > 言語（再起動後に適用）** で、システムに従う、English、简体中文、日本語から選択できます。設定は保存され、**Composa の再起動後に適用されます**。

システムに従う場合、中国本土・シンガポール・`zh-Hans` のロケールでは簡体字中国語、日本語のシステムでは日本語、それ以外では英語を使用します。初期対応は主なメニュー、共通ボタン、一部のダイアログとツールオプション、描画モード、一部の履歴名です。未対応のヒントや複雑なフィルターの説明は英語で表示されます。キャンバス上の文字、ユーザーが付けたレイヤー名、ファイルパスは自動翻訳されません。

## 機能

### レイヤー

- レイヤーとフォルダー、不透明度、Photoshop と同様に分類された描画モード。
- 境界線、ドロップシャドウ、光彩（外側・内側）、カラーオーバーレイ、シャドウ（内側）。ライブプレビューと Alt ドラッグによる効果のコピー。
- レイヤー、フォルダー、調整レイヤーのマスク。描画、塗りつぶし、グラデーション、反転、ぼかし、適用、無効化。
- クリッピングマスク（Alt クリックまたは Ctrl+Alt+G）、調整レイヤー、結合、グループの結合、画像の統合。
- 複数レイヤーの複製、名前の直接編集、ドラッグによる並べ替えと階層化、Alt ドラッグでの複製。プロジェクト間のコピーとペースト。
- 目のアイコン列をドラッグして複数レイヤーの表示を切り替え、Alt クリックで一つだけを表示。

### 変形と選択範囲

- 非破壊の移動、拡大縮小、回転、反転。小さく表示しても元画像の解像度を保持。
- 角を Ctrl ドラッグして自由に変形。どのツールでも Ctrl ドラッグで一時的にレイヤーを移動。
- 自動選択、複数レイヤーやフォルダー全体の変形、端と中心へのスナップ、位置・サイズ・角度の数値指定。
- 長方形、角丸長方形、楕円、直線の編集可能なシェイプ。拡大縮小時も鮮明に再描画。
- 長方形・楕円形選択、自由・多角形なげなわ、マジックワンド、オブジェクト選択。追加、削除、共通範囲。
- 全選択、反転、被写体選択、色域指定、拡張、縮小、境界のぼかし、レイヤーやマスクからの選択範囲読み込み。
- コンテンツに応じた塗りつぶし。画像の端の外側への拡張にも対応。

### 描画とレタッチ

- サイズ、硬さ、不透明度、滑らかさを調整できるブラシと消しゴム。Shift クリックで直線を描画。
- コンテンツに応じたスポット修復ブラシ、位置合わせを選べるコピースタンプ。単一または全レイヤーをサンプル。
- ゆがみ、ぼかし、指先、覆い焼き、焼き込み。両端を調整できる線形・円形グラデーション。
- ポイントテキストと段落テキスト。フォント、サイズ、スタイル、色、配置、字間、行送りを調整し、文字ごとの書式にも対応。
- スポイト、カラーピッカー、ペンタブレットの筆圧。描画ツールはマスクにも使用可能。

### 色調補正とフィルター

- レベル補正、トーンカーブ、色相・彩度、露光量、グラデーションマップ、カラールックアップ、粒子、明るさ・コントラスト、階調の反転。
- 6 色の重みと着色を指定できる白黒変換。シャドウ、中間調、ハイライト別のカラーバランス。
- `.cube` / `.3dl` の LUT、4 種のフィルムルック、色調補正を `.cube` として書き出す機能。
- ガウスぼかし、移動ぼかし、シャープ、ノイズ、レンズ補正、周辺光量、ブルーム、トーンコントラスト、各種ディザ。
- Camera Raw フィルターのライト、カラー、効果、カーブ、カラーミキサー、カラーグレーディング、ディテール、光学、キャリブレーション。
- 画像の構造に沿った筆触で絵画風に変換する Painterly。ライブプレビューに対応し、選択範囲がある場合はその範囲だけに適用。

### キャンバスとファイル

- 複数プロジェクトのタブ、切り抜き比率プリセットとスナップ。Shift で比率を固定、Alt で対称に切り抜き。
- カンバスサイズ、画像サイズ、トリミング、回転、定規、ガイド、グリッド、設定可能なスナップ。
- PNG、JPEG、WebP、BMP、GIF。ImageMagick 経由で HEIC、AVIF、TIFF、SVG、カメラ RAW を読み込み。
- カメラ RAW は露光量、ホワイトバランス、ノイズ低減、ハイライト復元、手動の放射状レンズ補正を調整し、16 ビットを保持したまま読み込み。続けて Camera Raw を開くこともできます。
- 16 ビット PNG/TIFF/HEIF と OpenEXR/Radiance HDR に対応。レイヤーの右クリックで 8/16 ビットを切り替え、表示メニューから ICC ソフトプルーフ、色域警告、保存される CMYK プロファイルを設定できます。
- Photoshop `.psd` / `.psb` と GIMP `.xcf` を読み込み。変換・省略される項目を適用前に表示。
- PNG、JPEG（圧縮結果とサイズのプレビュー付き）、WebP の書き出し。「形式を指定して書き出し」ではサイズ変更、TIFF、単ページ PDF、16 ビット PNG/TIFF、HDR EXR、印刷プロファイル付き CMYK JPEG/TIFF/PDF に対応。履歴はメモリーで制限。
- ツールの長押しまたは右クリックでグループを展開。ツールと表示設定を次回起動時にも保持。
- 未保存の作業を 2 分ごとに復旧用コピーとして保存し、異常終了後に復元を案内。

## AI による操作

**ヘルプ > AI による操作を許可** で [Model Context Protocol](https://modelcontextprotocol.io) サーバーを有効にします。初期状態は無効で、設定は保存されます。AI はユーザー専用パイプでアプリと通信し、接続状態はステータスバーに表示されます。操作は通常の編集コマンドを通るため、結果が画面に反映され、Ctrl+Z で元に戻せます。

Claude Code の場合は、作業フォルダーで次を実行します。

```bash
claude mcp add composa -- composa --mcp
```

`--mcp` の後に `--launch` を追加すると、最初の接続時にアプリが起動していなければ起動します。ブリッジはアプリ終了後も動作し、再起動するとツール一覧が再び利用可能になります。

AI はドキュメントの作成・読み込み・保存・書き出し、レイヤーの管理と変形、筆触・シェイプ・文字の描画、色調補正と大部分のフィルター、選択範囲の作成・変更、キャンバスのレンダリングを行えます。`sample_color` は色を取得し、`trace_edges` は輪郭の折れ線を返し、`paint_strokes` は複数の筆触をまとめて描きます。ドキュメント、レイヤー、画像は MCP リソースとしても提供されます。詳しくは英語の [AI 操作ガイド](docs/ai-control.md)と[ツールリファレンス](docs/ai-tools-reference.md)をご覧ください。ツール名と引数名は英語のままです。

## macOS 版との違い

- プロジェクトは `.cmps`（JSON、PNG レイヤー・マスク、浮動小数点 EXR を含む ZIP）で保存。形式 7 は元の精度と旧形式の読み込みに対応します。元アプリの `.comp` は読み込めません。
- 被写体検出は U²-Net lite / MODNet をローカル実行します。単色背景の方式も選択でき、フォールバックにも使われます。
- Windows は ImageMagick を同梱し、Linux の拡張形式はシステム側の ImageMagick を使用します。SVG は librsvg で描画するため表示が異なる場合があります。
- マスクはレイヤーと一緒に移動・拡大縮小し、個別には変形できません。タブ間の移動はコピーとペーストで行います。
- 色相・彩度の色域は固定です。スライダーはダブルクリックで数値を入力し、編集中にリセットボタンが表示されます。
- Photoshop は 8/16 ビット RGB と CMYK を読み込み、埋め込み ICC で色変換します。一部の文字、スマートオブジェクト、パスはピクセルに変換され、レイヤー効果と未対応の調整は省略されます。変更内容は読み込み前に表示されます。
- RAW の露光量とホワイトバランスはセンサーデータではなくデコード後の画像に適用します。
- Camera Raw はヒストグラム/ベクトルスコープ、実測カラー表、領域別シャドウ補正を備えます。対応する単一レイヤーの色調整はシェーダー、それ以外は非同期 CPU でプレビューします。Upright などは未対応で、RAW のレンズ補正は手動の放射状補正です。
- EXR のネイティブ読み込みは無圧縮/ZIPS/ZIP スキャンラインに対応。他の構成は HDRI ImageMagick（Windows 同梱）が必要です。詳細は[英語の互換性一覧](docs/compatibility/compositor-1.5.3-audit.md)をご覧ください。
- 外部プログラムで変更されたプロジェクトは自動再読み込みしません。更新の自動インストールや実行中ファイルの置換も行いません。

詳細は[英語版の比較](README.md#differences-from-the-macos-app)をご覧ください。

## ダウンロードとインストール

このフォークの[リリースページ](https://github.com/bianzuilun/Composa/releases)から、言語対応と機能更新を含む x86-64 / arm64 版を入手できます。.NET の別途インストールは不要です。

| 形式 | 対象 | 使用方法 |
| --- | --- | --- |
| `-setup.exe` | Windows 10 / 11 | インストーラーを実行。スタートメニューと `.cmps` の関連付けを追加 |
| `-win-x64.zip` | Windows | 展開して `composa.exe` を実行 |
| `.AppImage` | Linux | 実行権限を付けて実行 |
| `.deb` | Debian / Ubuntu など | apt でインストール |
| `.rpm` | Fedora / RHEL / openSUSE | 対応するパッケージマネージャーでインストール |
| `.tar.gz` | Linux | 展開後に `install.sh` を実行。標準では `~/.local` に配置 |

Windows on Arm では `win-arm64` を選びます。Windows 版はまだコード署名されていないため、SmartScreen の確認画面が表示される場合があります。配布元とリリースのチェックサムを確認してください。アンインストールは Windows の「設定 > アプリ」から行えます。設定は `%APPDATA%\Composa` に残ります。

```bash
# ダウンロードの検証
sha256sum -c sha256sums.txt --ignore-missing

# AppImage
chmod +x Composa-*.AppImage && ./Composa-*.AppImage

# Debian / Ubuntu（arm64 では対応するパッケージを選択）
sudo apt install ./composa_*_amd64.deb

# Fedora / RHEL
sudo dnf install ./composa-*.x86_64.rpm

# 現在のフォルダーにある Linux ポータブル版
tar xzf composa-*-linux-x64.tar.gz && cd composa-*-linux-x64 && ./install.sh
```

Windows では次のハッシュを `sha256sums.txt` の該当ファイルと比較します。

```powershell
Get-FileHash .\composa-*-setup.exe
```

Linux には Fontconfig と一般的な X11 デスクトップライブラリが必要です。ImageMagick は拡張形式を開く場合のみ必要な任意依存です。Windows には同梱され、ライセンス通知も付属します。

## 更新

アプリは上流 GitHub のリリースを 1 日に最大 1 回、匿名で確認します。ダウンロードを押したときだけ、プラットフォームとインストール方法に対応するファイルを取得し、SHA-256 を検証します。インストールボタンはシステムのインストーラーに処理を渡します。Windows では未保存の作業を確認してからアプリを終了します。自動ダウンロード、自動インストール、自己置換は行いません。

自動確認はヘルプメニューまたは `COMPOSA_DISABLE_UPDATE_CHECK=1` で無効にできます。手動確認は引き続き利用できます。リクエストにバージョン、機器識別子、テレメトリーは含まれません。`UPDATE_CHANNEL=managed` の配布では更新をパッケージマネージャーに任せます。詳細は[設定と更新](docs/settings-and-updates.md)をご覧ください。

## ソースからビルド

.NET 10 SDK が必要です。RPM の作成には `rpmbuild`、Windows インストーラーには Inno Setup 6 も必要です。

```bash
dotnet build
dotnet run --project src/Composa.App

# 指定したファイルを開く
dotnet run --project src/Composa.App -- photo.jpg project.cmps

# Linux の全パッケージ / ポータブル版
scripts/package/all.sh
scripts/publish.sh

# Windows の Git Bash から実行。Linux では --no-installer を追加して ZIP のみ作成
scripts/package/windows.sh win-x64
```

## テスト

```bash
dotnet test
```

`tests/Composa.Core.Tests` は編集コマンド、合成、ファイル形式、ランダム操作の回帰を検証します。`tests/Composa.App.Tests` は Avalonia のヘッドレス環境と Skia で実際の UI を操作し、`artifacts/screenshots/` にスクリーンショットを保存します。
